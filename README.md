# یوزربات تلگرام + ربات کنترل (Railway + GitHub)

**چه کار می‌کند؟**
برنامه با اکانت خودت وارد تلگرام می‌شود (یوزربات). هر وقت در گپی که تعیین کرده‌ای پیامی با کلمه‌ی مورد نظر بیاید، دکمه‌ی انتخابی همان پیام را می‌زند.
قوانین (گپ، کلمه، دکمه) را از داخل تلگرام و با یک ربات کنترل (توکن BotFather) تنظیم می‌کنی؛ فقط خودت به آن دسترسی داری.

---

## قدم ۱: گرفتن API_ID و API_HASH
1. برو به https://my.telegram.org و با شماره‌ات وارد شو.
2. روی **API development tools** برو و یک اپ بساز (اسم و توضیح هرچه خواستی).
3. مقدار `api_id` و `api_hash` را کپی کن.

## قدم ۲: ساخت ربات کنترل و گرفتن توکن
1. در تلگرام به @BotFather برو و `/newbot` بزن.
2. اسم و یوزرنیم (که با `bot` تمام شود) بده.
3. توکنی که می‌دهد همان `BOT_TOKEN` است.
4. **حتماً** وارد رباتِ جدیدت شو و یک بار `Start` بزن (وگرنه نمی‌تواند به تو پیام بدهد).

## قدم ۳: گرفتن آیدی عددی خودت (OWNER_ID)
به @userinfobot در تلگرام پیام بده؛ عددی که می‌دهد `OWNER_ID` است.

## قدم ۴: گرفتن SESSION_STRING (فقط یک بار، روی کامپیوتر یا گوشی)
```
pip install telethon
python generate_session.py
```
- `API_ID` و `API_HASH` را وارد کن، بعد شماره‌ات (با کد کشور، مثل `+98...`)، کدی که تلگرام می‌فرستد و در صورت وجود رمز دومرحله‌ای.
- **کد ورود را داخل هیچ چتی در تلگرام ننویس** (تلگرام آن را باطل می‌کند). فقط در همان برنامه وارد کن.
- متن طولانی خروجی همان `SESSION_STRING` است. آن را در جای امن نگه دار.

> ⚠️ هر کس این متن را داشته باشد کنترل کامل اکانتت را دارد. در گیت‌هاب یا هیچ‌جای عمومی نگذارش.
> اگر لو رفت: تلگرام ← Settings ← Devices ← همه‌ی نشست‌های ناشناس را Terminate کن.

اگر پایتون نداری، می‌توانی همین دو دستور را در Google Colab اجرا کنی (`!pip install telethon` و بعد کد `generate_session.py` را در یک سلول بگذار).

## قدم ۵: آپلود در گیت‌هاب
1. در github.com یک ریپوی جدید بساز و حتماً **Private** انتخاب کن.
2. فایل‌های همین پوشه را داخلش آپلود کن. یا با گیت:
```
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```
(فایل `.gitignore` جلوی آپلود فایل‌های محرمانه را می‌گیرد؛ هیچ‌وقت فایل `.env` نساز و آپلود نکن.)

## قدم ۶: دیپلوی در Railway
1. در railway.com: **New Project ← Deploy from GitHub repo** و ریپویت را انتخاب کن.
2. روی سرویس کلیک کن ← تب **Variables** و این‌ها را اضافه کن:

| نام | مقدار |
|---|---|
| `API_ID` | از قدم ۱ |
| `API_HASH` | از قدم ۱ |
| `SESSION_STRING` | از قدم ۴ |
| `BOT_TOKEN` | از قدم ۲ |
| `OWNER_ID` | از قدم ۳ |
| `DATA_DIR` | `/data` |

3. **Volume بساز** (مهم، وگرنه با هر دیپلوی مجدد قوانینت پاک می‌شود): روی سرویس ← Settings (یا کلیک راست روی بوم) ← **Add Volume** و Mount Path را `/data` بگذار.
4. دیپلوی خودکار شروع می‌شود. در تب **Deployments ← Logs** باید این‌ها را ببینی:
   - `یوزربات وارد شد: ...`
   - `ربات کنترل آماده است`
5. همان لحظه یک پیام «✅ برنامه روشن شد» در رباتِ کنترل برایت می‌آید.

## قدم ۷: استفاده
در رباتِ کنترل:

| دستور | کار |
|---|---|
| `/add` | افزودن قانون مرحله‌به‌مرحله (گپ ← کلمه ← دکمه) |
| `/add @گپ \| کلمه \| دکمه` | افزودن سریع، مثلاً `/add @some_bot \| پیروز \| تایید` |
| `/list` | لیست قوانین (با دکمه‌ی حذف) |
| `/del 3` | حذف قانون شماره ۳ |
| `/on` و `/off` | روشن / خاموش کردن کل یوزربات |
| `/status` | وضعیت |

**نکته‌ها برای قانون:**
- **گپ:** یوزرنیم (`@name`)، آیدی عددی یا لینک `t.me/...`. اکانتت باید عضو آن گپ باشد یا قبلاً با آن ربات چت کرده باشد.
- **کلمه:** اگر در متن پیام باشد (حروف بزرگ/کوچک مهم نیست) فعال می‌شود. با `*` یعنی هر پیام.
- **دکمه:** یا متن دکمه (مثل `تایید`؛ حتی بخشی از متن هم کافی است)، یا شماره‌ی دکمه به شکل `#1`، `#2` (شمارش از بالا-چپ به پایین، از ۱).
- تأخیر پیش‌فرض ۱ ثانیه است (متغیر `DEFAULT_DELAY`). در حالت سریع می‌توانی چهارمی را بدهی: `/add @bot | کلمه | دکمه | 2`.
- دکمه فقط برای پیام‌هایی زده می‌شود که **دکمه‌ی شیشه‌ای (inline) یا کیبورد** دارند و **از طرف دیگران** آمده‌اند (نه پیام‌های خودت).

---

## عیب‌یابی
- **`SESSION_STRING نامعتبر`**: دوباره قدم ۴ را بزن و مقدار جدید را در Variables بگذار.
- **`AuthKeyDuplicatedError` یا نشست خودبه‌خود بسته می‌شود**: همزمان در دو جا (مثلاً Railway و کامپیوترت) با یک SESSION_STRING اجرا کرده‌ای. فقط یک جا اجرا کن و اگر لازم شد دوباره بساز.
- **ربات پیام شروع نفرستاد**: در رباتِ کنترل `Start` بزن و `OWNER_ID` را چک کن. هر کس دیگری به ربات پیام بدهد فقط آیدی عددی خودش را می‌بیند.
- **دکمه زده نمی‌شود**: لاگ را ببین. معمولاً متن دکمه فرق دارد (ایموجی/فاصله) یا قانون روی گپ اشتباه است. با `#شماره` امتحان کن.
- **گپ پیدا نشد**: اکانتت باید آن را در لیست چت‌هایش داشته باشد؛ لینک دعوت خصوصی (`t.me/+...`) پشتیبانی نمی‌شود، از آیدی عددی استفاده کن.
- **بعد از ری‌استارت قوانین پاک شد**: Volume را روی `/data` نگذاشته‌ای یا `DATA_DIR=/data` را ست نکرده‌ای.

## هشدار
- زدن خیلی سریع و پرتعداد دکمه‌ها ممکن است تلگرام را حساس کند و اکانت محدود شود؛ تأخیر معقول بگذار و فقط برای کار مشخص استفاده کن.
- مسئولیت استفاده از اکانت با خودت است و ربات فقط روی گپ‌هایی که تعریف می‌کنی کار می‌کند.
